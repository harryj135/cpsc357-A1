# README
## How do I use this program?
Please use Minix to compile and run this program.
Compile the contents of this directory in Minix with the following:
```
cc cpsc457−a1.c −o ./cpsc457−a1
```

Run the program and provide up to 8 numbers you would like to compute the Fibonacci sequence for.

For example:
```
./cpsc457-a1 1 2 3
```
Will compute the 1st, 2nd, and 3rd numbers in the Fibonacci sequence.
